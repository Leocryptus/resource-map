# CRYPTUS — карта публичных ресурсов

Инвентарь публичных сущностей бренда CRYPTUS / Cryptus Media / UNION для аудита и закрытия.

**Дашборд:** открой `index.html` через GitHub Pages.

- Сгруппировано по типу (воронки, соцсети, домены, Union, обменник, смежные бренды, упоминания).
- Каждая сущность кликабельна, со скриншотом или иконкой платформы.
- Чекбоксы «закрыто» — прогресс сохраняется в браузере.

Страница закрыта от индексации поисковиками (`noindex`) — доступна только по ссылке.
